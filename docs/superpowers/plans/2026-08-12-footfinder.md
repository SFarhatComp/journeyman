# FootFinder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private multiplayer football trivia game where friends claim distinct clubs, then race to name a footballer whose career covers as many of those clubs as possible.

**Architecture:** One Node container, no database. A pure engine module (state machine + scoring) with zero I/O sits under a thin Fastify + WebSocket shell. The player dataset is extracted from Wikidata at build time into a JSON file baked into the image and loaded into memory at boot, so the game never calls Wikidata at runtime.

**Tech Stack:** Node 22 (ESM), Fastify, `ws`, plain HTML/CSS/JS frontend, `node --test`. Docker for everything.

## Global Constraints

- **Node 22, ESM only.** `"type": "module"` in package.json. No CommonJS.
- **Runtime dependencies are exactly `fastify` and `ws`.** No frontend framework, no build step, no database, no ORM.
- **Nothing runs on the host.** Every command — install, test, run — executes inside Docker via `./footfinder.sh`. Never instruct the user to run `npm` or `node` directly.
- **Tests are offline and pure.** No network, no timers, no sockets in engine tests. Time is injected as a `now` parameter, never read from `Date.now()` inside the engine.
- **Run tests with the glob form:** `node --test "test/*.test.js"`. The directory form (`node --test test/`) is broken on Node 22.23+.
- **The engine never imports the transport or dataset layers.** Data access is injected as a `deps` object.
- **The autocomplete must never emit a club name.** This is a game-correctness rule, not a style preference: showing clubs hands over the exact knowledge the game tests.
- **The server binds `127.0.0.1` only.** Never `0.0.0.0`.
- **The container runs as a non-root user.**
- Caps: 24-character nicknames, 8 players per room, 4 KB messages, 6-character room codes.

```bash
             --log-opt max-size=10m --log-opt max-file=3 "$IMAGE"
           echo "up on http://127.0.0.1:3000" ;;

  down)    docker rm -f "$NAME" >/dev/null 2>&1 && echo stopped || echo "not running" ;;
  logs)    docker logs -f --tail 100 "$NAME" ;;

  tunnel)  echo "Public URL for friends (Ctrl-C to close):"

  dataset) docker run --rm -v "$DIR/data:/app/data" -v "$DIR/scripts:/app/scripts:ro" \
```

```javascript
/**
 * Scoring. Pure set maths — no I/O, no dataset knowledge beyond the shape
 * `{ id, name, clubIds }`.
 *
 * A player's score for a round is simply how many of that round's chosen clubs
 * they played for. Because the round's clubs are distinct (taken clubs lock
 * out), the maximum equals the number of players.
 */

/** @returns {{points:number, matchedClubIds:string[]}} */
export function scoreAnswer(playerClubIds, roundClubIds) {
  const round = new Set(roundClubIds);
  // Set, not filter: two spells at one club is still one club.
  const matched = new Set();
  for (const id of playerClubIds) if (round.has(id)) matched.add(id);
  const matchedClubIds = [...matched];
  return { points: matchedClubIds.length, matchedClubIds };
}

/**
 * The best answer available in the dataset for this round. Shown at reveal so
 * every round teaches something, and so the game can prove it was winnable.
 * Linear over ~25k players — trivially fast at this scale.
 */
export function findBestAnswer(roundClubIds, allPlayers) {
  let best = null;
  for (const p of allPlayers) {
    const { points, matchedClubIds } = scoreAnswer(p.clubIds, roundClubIds);
    if (points === 0) continue;
    if (!best || points > best.points) {
      best = { entityId: p.id, name: p.name, points, matchedClubIds };
    }
  }
  return best;
}
```

Create `src/dataset/label.js`:

```javascript
/**
 * The label shown in the answer autocomplete.
 *
 * THE RULE: a label must never reveal which clubs a player played for. That is
 * precisely the knowledge the game tests, so a hint like
 * "Ronaldo (Barcelona, Inter)" would hand over the answer.
 *
 * Every player gets the same shape — "C. Ronaldo (1985, PT)" — so there is no
 * collision detection, no tiering, and no need to see other players. An
 * earlier design escalated through tiers depending on whether a name was
 * unique; it produced a tier that could never execute. Uniformity removes that
 * class of bug by construction.
 *
 * Birth year and country are far weaker signals than clubs, and are only seen
 * after a name is typed — they cannot help find an answer, only confirm which
 * person was meant.
 */

// Particles belong to the surname, not the given names.
const PARTICLES = new Set(["da", "de", "del", "della", "di", "dos", "du", "la", "le", "van", "von", "der", "den", "ten", "ter"]);

/** "Luís Carlos Almeida da Cunha" -> "L. da Cunha"; "Hulk" -> "Hulk". */
function shortName(name) {
  const parts = String(name).trim().split(/\s+/);
  if (parts.length === 1) return parts[0];

  // Walk back over particles so multi-word surnames stay intact.
  let i = parts.length - 1;
  while (i > 1 && PARTICLES.has(parts[i - 1].toLowerCase())) i--;

  return `${parts[0][0].toUpperCase()}. ${parts.slice(i).join(" ")}`;
}

/** @param {{name:string, birthYear?:number, country?:string}} player */
export function formatLabel(player) {
  const suffix = [player.birthYear, player.country].filter(Boolean).join(", ");
  return suffix ? `${shortName(player.name)} (${suffix})` : shortName(player.name);
}
```

```javascript
/**
 * The sole adapter between Wikidata's response shape and the game's dataset.
 * Pure — the network call lives in scripts/build-dataset.mjs.
 *
 * Swapping to a Transfermarkt-derived source later means rewriting this file
 * and nothing else.
 */

const qid = (url) => String(url).split("/").pop();

/**
 * @param {Array<{id:string,name:string,country:string}>} clubs curated list
 * @param {Array<object>} rows raw SPARQL bindings
 * @returns {{clubs:Array, players:Array<{id,name,birthYear,clubIds}>}}
 */
export function shapeDataset(clubs, rows) {
  const curated = new Set(clubs.map((c) => c.id));
  const byPlayer = new Map();

  for (const r of rows) {
    const id = qid(r.player.value);
    const name = r.playerLabel?.value;

    // Wikidata echoes the QID as the label when there is no English label.
    // Such a player is unnameable in the UI, so drop the row.
    if (!name || name === id) continue;

    const clubId = qid(r.club.value);
    // Restricting to the curated list is load-bearing: it keeps national teams
    // out and avoids ever having to classify an arbitrary team.
    if (!curated.has(clubId)) continue;

    if (!byPlayer.has(id)) {
      const year = r.dob?.value ? Number(String(r.dob.value).slice(0, 4)) : undefined;
      byPlayer.set(id, {
        id,
        name,
        birthYear: Number.isFinite(year) ? year : undefined,
        countries: new Set(),
        clubIds: new Set(),
      });
    }
    const entry = byPlayer.get(id);
    entry.clubIds.add(clubId);
    // Wikidata emits one row per citizenship; collect then pick one, so a
    // dual national's label cannot flap between builds.
    if (r.iso?.value) entry.countries.add(String(r.iso.value).toUpperCase());
  }

  const players = [...byPlayer.values()]
    .map(({ countries, ...p }) => ({
      ...p,
      country: [...countries].sort()[0],
      clubIds: [...p.clubIds].sort(),
    }))
    .sort((a, b) => a.id.localeCompare(b.id)); // deterministic output

  return { clubs, players };
}
```

Create `src/dataset/load.js`:

```javascript
import { formatLabel } from "./label.js";

/**
 * Loads the baked dataset into memory and exposes lookup + autocomplete.
 *
 * At ~25k players a linear scan per keystroke is fine (single-digit
 * milliseconds), so there is no index to keep in sync. Normalisation is
 * precomputed once because that is the part that would actually cost.
 */

/** Lowercase and strip accents, so "ibrahimovic" finds "Ibrahimović". */
export function normalize(s) {
  return String(s)
    .normalize("NFD")
    .replace(/\p{Diacritic}/gu, "")
    .toLowerCase()
    .trim();
}

export function createDataset({ clubs, players }) {
  const byId = new Map(players.map((p) => [p.id, p]));

  // Precomputed search keys: the whole name plus each word, so "Ibra" and
  // "Zlatan" both hit.
  const searchable = players.map((p) => {
    const norm = normalize(p.name);
    return { id: p.id, label: formatLabel(p), norm, words: norm.split(/\s+/) };
  });

  function search(query, limit = 8) {
    const q = normalize(query);
    if (q.length < 2) return [];

    const results = [];
    for (const entry of searchable) {
      // Prefix match on the full name or any word within it.
      if (entry.norm.startsWith(q) || entry.words.some((w) => w.startsWith(q))) {
        results.push(entry);
        if (results.length >= limit * 4) break; // bounded work per keystroke
      }
    }
    // Whole-name prefix matches first, then alphabetical for stability.
    results.sort((a, b) => {
      const aStarts = a.norm.startsWith(q) ? 0 : 1;
      const bStarts = b.norm.startsWith(q) ? 0 : 1;
      return aStarts - bStarts || a.norm.localeCompare(b.norm);
    });

    return results.slice(0, limit).map(({ id, label }) => ({ id, label }));
  }

  return {
    clubs,
    players,
    getPlayer: (id) => byId.get(id) ?? null,
    getPlayerClubs: (id) => byId.get(id)?.clubIds ?? [],
    search,
  };
}
```

```javascript
/**
 * Builds data/dataset.json from Wikidata. Run manually: ./footfinder.sh dataset
 *
 * Deliberately NOT part of the test run or the image build — pointing
 * scheduled traffic at a public endpoint would be rude, and an upstream
 * outage must not break the build.
 */
import { readFile, writeFile } from "node:fs/promises";
import { shapeDataset } from "../src/dataset/fromWikidata.js";

const ENDPOINT = "https://query.wikidata.org/sparql";
const UA = "footfinder/0.1 (personal football trivia game)";

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

async function fetchClubRoster(clubId) {
  // P54 = member of sports team. Fetch per club so each query stays small
  // enough to beat the endpoint's 60s timeout.
  const query = `
    SELECT ?player ?playerLabel ?dob ?iso ?club WHERE {
      ?player p:P54/ps:P54 wd:${clubId} .
      ?player wdt:P31 wd:Q5 .
      BIND(wd:${clubId} AS ?club)
      OPTIONAL { ?player wdt:P569 ?dob }
      # P27 = country of citizenship, P297 = its ISO 3166-1 alpha-2 code.
      # A dual national yields one row per citizenship; the adapter picks one.
      OPTIONAL { ?player wdt:P27/wdt:P297 ?iso }
      SERVICE wikibase:label { bd:serviceParam wikibase:language "en". }
    }`;

  for (let attempt = 0; attempt < 3; attempt++) {
    const res = await fetch(`${ENDPOINT}?query=${encodeURIComponent(query)}`, {
      headers: { Accept: "application/sparql-results+json", "User-Agent": UA },
    });
    if (res.ok) return (await res.json()).results.bindings;
    if (res.status === 429 || res.status >= 500) {
      const wait = 2000 * (attempt + 1);
      console.log(`  ${clubId}: HTTP ${res.status}, retrying in ${wait}ms`);
      await sleep(wait);
      continue;
    }
    throw new Error(`${clubId}: HTTP ${res.status}`);
  }
  throw new Error(`${clubId}: failed after 3 attempts`);
}

const clubs = JSON.parse(await readFile(new URL("../data/clubs.json", import.meta.url), "utf8"));
console.log(`Fetching rosters for ${clubs.length} clubs…`);

const rows = [];
for (const [i, club] of clubs.entries()) {
  const roster = await fetchClubRoster(club.id);
  rows.push(...roster);
  console.log(`  [${i + 1}/${clubs.length}] ${club.name}: ${roster.length} players`);
  await sleep(1000); // be a good citizen
}

const dataset = shapeDataset(clubs, rows);
if (dataset.players.length === 0) throw new Error("dataset is empty — refusing to write");

await writeFile(
  new URL("../data/dataset.json", import.meta.url),
  JSON.stringify(dataset),
);
console.log(`\nWrote ${dataset.players.length} players across ${dataset.clubs.length} clubs.`);
```

Create `src/engine/room.js`:

```javascript
/**
 * The room state machine. Pure: every mutator takes the current state and
 * returns a new one, never reads the clock (time arrives as `now`), and never
 * touches the dataset directly (it arrives as `deps`).
 *
 * That is what lets the claim race, the grace window and phase expiry be
 * tested exhaustively without sockets or waiting in real time.
 *
 * Phases: LOBBY -> PICKING -> ANSWERING -> REVEAL -> (PICKING | FINAL)
 */

export const DEFAULT_CONFIG = {
  rounds: 8,
  pickSeconds: 15,
  answerSeconds: 30,
  revealSeconds: 8,
  graceSeconds: 5,
  maxPlayers: 8,
  minPlayers: 2,
};

const clone = (state) => structuredClone(state);
const ok = (state, events = []) => ({ state, events });
const fail = (state, error) => ({ state, events: [], error });

export function createRoom({ code, config = {} }) {
  return {
    code,
    hostId: null,
    phase: "LOBBY",
    config: { ...DEFAULT_CONFIG, ...config },
    players: [],
    round: null,
    phaseEndsAt: null,
    history: [],
  };
}

export function addPlayer(state, { id, nickname }) {
  const next = clone(state);
  const existing = next.players.find((p) => p.id === id);

  if (existing) {
    // Reconnection: keep the score, mark them back online.
    existing.connected = true;
    return ok(next, [{ type: "player_reconnected", playerId: id }]);
  }
  if (next.players.length >= next.config.maxPlayers) return fail(state, "room_full");
  if (next.players.some((p) => p.nickname === nickname)) return fail(state, "nickname_taken");

  next.players.push({ id, nickname, score: 0, connected: true });
  if (!next.hostId) next.hostId = id;
  return ok(next, [{ type: "player_joined", playerId: id }]);
}

export function startGame(state, now, deps) {
  if (state.phase !== "LOBBY") return fail(state, "already_started");
  if (state.players.length < state.config.minPlayers) return fail(state, "not_enough_players");
  // Clubs lock out when taken, so every player needs one available.
  if (deps.clubs.length < state.players.length) return fail(state, "not_enough_clubs");

  const next = clone(state);
  return ok(beginRound(next, 1, now), [{ type: "game_started" }]);
}

/** Shared by startGame and the reveal->next-round transition. */
export function beginRound(state, number, now) {
  state.phase = "PICKING";
  state.round = {
    number,
    picks: {},        // playerId -> clubId
    answers: {},      // playerId -> { entityId, submittedAt }
    grace: {},        // playerId -> deadline ms
    results: null,
    bestAnswer: null,
  };
  state.phaseEndsAt = now + state.config.pickSeconds * 1000;
  return state;
}
```

```javascript
export function pickClub(state, { playerId, clubId }, now, deps) {
  if (state.phase !== "PICKING") return fail(state, "wrong_phase");
  if (!deps.clubs.some((c) => c.id === clubId)) return fail(state, "unknown_club");

  const takenBy = Object.entries(state.round.picks).find(([pid, cid]) => cid === clubId && pid !== playerId);
  if (takenBy) return fail(state, "club_taken");

  const next = clone(state);
  next.round.picks[playerId] = clubId;

  const events = [{ type: "club_picked", playerId, clubId }];

  // Advance the moment everyone has acted — otherwise a room of fast players
  // watches a dead countdown every round.
  if (Object.keys(next.round.picks).length === next.players.length) {
    beginAnswering(next, now);
    events.push({ type: "phase_changed", phase: "ANSWERING" });
  }
  return ok(next, events);
}

function beginAnswering(state, now) {
  state.phase = "ANSWERING";
  state.phaseEndsAt = now + state.config.answerSeconds * 1000;
}

/** Assign a free club at random to a player who ran out of time. */
function autoAssign(state, deps) {
  const taken = new Set(Object.values(state.round.picks));
  const free = deps.clubs.filter((c) => !taken.has(c.id));
  const rand = deps.random ?? Math.random;

  for (const player of state.players) {
    if (state.round.picks[player.id]) continue;
    const idx = Math.floor(rand() * free.length);
    const club = free.splice(idx, 1)[0];
    // startGame guarantees clubs.length >= players.length, so this holds.
    state.round.picks[player.id] = club.id;
  }
}

export function expirePhase(state, now, deps) {
  if (state.phaseEndsAt === null || now < state.phaseEndsAt) return ok(state);

  const next = clone(state);
  if (next.phase === "PICKING") {
    autoAssign(next, deps);
    beginAnswering(next, now);
    return ok(next, [{ type: "phase_changed", phase: "ANSWERING" }]);
  }
  return ok(next);
}
```

```javascript
export function submitAnswer(state, { playerId, entityId }, now, deps) {
  if (state.phase !== "ANSWERING") return fail(state, "wrong_phase");
  if (state.round.answers[playerId]) return fail(state, "already_answered");

  const claimed = Object.values(state.round.answers).some((a) => a.entityId === entityId);
  if (claimed) {
    // Losing a race by milliseconds must not cost the round, so the player is
    // given a personal extension to name someone else.
    const next = clone(state);
    next.round.grace[playerId] = now + next.config.graceSeconds * 1000;
    return { state: next, events: [{ type: "answer_rejected", playerId, entityId }], error: "already_claimed" };
  }

  const next = clone(state);
  next.round.answers[playerId] = { entityId, submittedAt: now };
  delete next.round.grace[playerId];

  const events = [{ type: "answer_accepted", playerId }];
  if (Object.keys(next.round.answers).length === next.players.length) {
    beginReveal(next, now, deps);
    events.push({ type: "phase_changed", phase: "REVEAL" });
  }
  return ok(next, events);
}

/** True while any player still has an unexpired grace window. */
function graceActive(state, now) {
  return Object.entries(state.round.grace).some(
    ([playerId, until]) => now < until && !state.round.answers[playerId],
  );
}

export function expirePhase(state, now, deps) {
  if (state.phaseEndsAt === null || now < state.phaseEndsAt) {
    // The deadline itself has not passed, but a grace window may have.
    return ok(state);
  }

  const next = clone(state);
  if (next.phase === "PICKING") {
    autoAssign(next, deps);
    beginAnswering(next, now);
    return ok(next, [{ type: "phase_changed", phase: "ANSWERING" }]);
  }

  if (next.phase === "ANSWERING") {
    if (graceActive(next, now)) return ok(state); // wait for the grace window
    beginReveal(next, now, deps);
    return ok(next, [{ type: "phase_changed", phase: "REVEAL" }]);
  }

  return ok(next);
}
```

```javascript
export function beginReveal(state, now, deps) {
  const roundClubIds = Object.values(state.round.picks);

  state.round.results = state.players.map((player) => {
    const answer = state.round.answers[player.id];
    if (!answer) {
      return { playerId: player.id, entityId: null, points: 0, matchedClubIds: [] };
    }
    const clubIds = deps.getPlayerClubs(answer.entityId);
    const round = new Set(roundClubIds);
    const matchedClubIds = [...new Set(clubIds.filter((c) => round.has(c)))];
    return { playerId: player.id, entityId: answer.entityId, points: matchedClubIds.length, matchedClubIds };
  });

  for (const result of state.round.results) {
    const player = state.players.find((p) => p.id === result.playerId);
    player.score += result.points;
  }

  // Shown so every round teaches something, and so the game can prove the
  // round was winnable.
  state.round.bestAnswer = deps.findBest(roundClubIds);
```

```javascript
/**
 * The socket boundary: validation on the way in, and the single definition of
 * what a client is allowed to see on the way out.
 */

export const MAX_MESSAGE_BYTES = 4096;
export const MAX_NICKNAME_LENGTH = 24;

const VALIDATORS = {
  join: (p) => typeof p?.nickname === "string"
    && p.nickname.trim().length > 0
    && p.nickname.length <= MAX_NICKNAME_LENGTH,
  start: () => true,
  pickClub: (p) => typeof p?.clubId === "string" && p.clubId.length <= 32,
  submitAnswer: (p) => typeof p?.entityId === "string" && p.entityId.length <= 32,
  search: (p) => typeof p?.query === "string" && p.query.length <= 64,
};

export function parseMessage(raw) {
  if (typeof raw !== "string" || Buffer.byteLength(raw, "utf8") > MAX_MESSAGE_BYTES) {
    return { error: "too_large" };
  }
  let msg;
  try {
    msg = JSON.parse(raw);
  } catch {
    return { error: "bad_json" };
  }
  const validate = VALIDATORS[msg?.type];
  if (!validate) return { error: "unknown_type" };
  if (!validate(msg.payload)) return { error: "bad_payload" };
  return { type: msg.type, payload: msg.payload ?? {} };
}

/**
 * What one player may see. Answers stay hidden until REVEAL — knowing what a
 * rival typed would let you copy it or dodge their claim.
 */
export function snapshotFor(state, playerId) {
  const base = {
    code: state.code,
    phase: state.phase,
    config: state.config,
    phaseEndsAt: state.phaseEndsAt,
    hostId: state.hostId,
    you: playerId,
    players: state.players.map((p) => ({ id: p.id, nickname: p.nickname, score: p.score, connected: p.connected })),
  };
  if (state.phase === "FINAL") return { ...base, standings: state.standings };
  if (!state.round) return base;

  const round = {
    number: state.round.number,
    picks: state.round.picks, // club lock-out must be visible to everyone
    answered: Object.fromEntries(Object.keys(state.round.answers).map((id) => [id, true])),
    myGraceEndsAt: state.round.grace[playerId] ?? null,
  };
  if (state.phase === "REVEAL") {
    round.results = state.round.results;
    round.bestAnswer = state.round.bestAnswer;
  }
  return { ...base, round };
}
```

Create `src/server.js`:

```javascript
import { readFile } from "node:fs/promises";
import { createServer } from "node:http";
import { WebSocketServer } from "ws";
import { randomUUID } from "node:crypto";
import { createDataset } from "./dataset/load.js";
import { findBestAnswer } from "./engine/scoring.js";
import { parseMessage, snapshotFor } from "./protocol.js";
import {
  createRoom, addPlayer, startGame, pickClub, submitAnswer, expirePhase, disconnect,
} from "./engine/room.js";

const PORT = Number(process.env.PORT ?? 3000);
const HOST = process.env.HOST ?? "127.0.0.1";

const raw = JSON.parse(await readFile(new URL("../data/dataset.json", import.meta.url), "utf8"));
const dataset = createDataset(raw);
console.log(`dataset: ${dataset.players.length} players, ${dataset.clubs.length} clubs`);

const deps = {
  clubs: dataset.clubs,
  getPlayerClubs: (id) => dataset.getPlayerClubs(id),
  findBest: (roundClubIds) => findBestAnswer(roundClubIds, dataset.players),
};

/** code -> { state, sockets: Map<playerId, ws> } */
const rooms = new Map();
const CODE_ALPHABET = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789"; // no I/O/0/1

function newCode() {
  let code;
  do {
    code = Array.from({ length: 6 }, () =>
      CODE_ALPHABET[Math.floor(Math.random() * CODE_ALPHABET.length)]).join("");
  } while (rooms.has(code));
  return code;
}

function broadcast(room) {
  for (const [playerId, ws] of room.sockets) {
    if (ws.readyState === ws.OPEN) {
      ws.send(JSON.stringify({ type: "snapshot", payload: snapshotFor(room.state, playerId) }));
    }
  }
}

function apply(room, result) {
  room.state = result.state;
  broadcast(room);
  return result;
}

// Static files. Tiny hand-rolled server — three files, no framework needed.
const MIME = { ".html": "text/html", ".js": "text/javascript", ".css": "text/css" };
const server = createServer(async (req, res) => {
  if (req.url === "/api/clubs") {
    res.writeHead(200, { "content-type": "application/json" });
    return res.end(JSON.stringify(dataset.clubs));
  }
  if (req.url?.startsWith("/api/search?")) {
    const q = new URL(req.url, "http://x").searchParams.get("q") ?? "";
    res.writeHead(200, { "content-type": "application/json" });
    return res.end(JSON.stringify(dataset.search(q)));
  }
  if (req.method === "POST" && req.url === "/api/room") {
    const code = newCode();
    rooms.set(code, { state: createRoom({ code }), sockets: new Map() });
    res.writeHead(200, { "content-type": "application/json" });
    return res.end(JSON.stringify({ code }));
  }

  const path = req.url === "/" ? "/index.html" : req.url.split("?")[0];
  if (!/^\/[\w.-]+$/.test(path)) { res.writeHead(404); return res.end(); }
  try {
    const body = await readFile(new URL(`../public${path}`, import.meta.url));
    const ext = path.slice(path.lastIndexOf("."));
    res.writeHead(200, { "content-type": MIME[ext] ?? "application/octet-stream" });
    res.end(body);
  } catch {
    res.writeHead(404);
    res.end("not found");
  }
});

const wss = new WebSocketServer({ server, path: "/ws", maxPayload: 4096 });

wss.on("connection", (ws, req) => {
  const url = new URL(req.url, "http://x");
  const code = (url.searchParams.get("code") ?? "").toUpperCase();
  const room = rooms.get(code);
  if (!room) return ws.close(4004, "no such room");

  // The client keeps this so a reload rejoins as the same player.
  const playerId = url.searchParams.get("playerId") || randomUUID();
  ws.send(JSON.stringify({ type: "identity", payload: { playerId } }));

  ws.on("message", (data) => {
    const msg = parseMessage(data.toString());
    if (msg.error) return ws.send(JSON.stringify({ type: "error", payload: { error: msg.error } }));

    const now = Date.now();
    let result;
    switch (msg.type) {
      case "join":
        result = addPlayer(room.state, { id: playerId, nickname: msg.payload.nickname.trim() });
        if (!result.error) room.sockets.set(playerId, ws);
        break;
      case "start":
        if (playerId !== room.state.hostId) result = { state: room.state, error: "not_host" };
        else result = startGame(room.state, now, deps);
        break;
      case "pickClub":
        result = pickClub(room.state, { playerId, clubId: msg.payload.clubId }, now, deps);
        break;
      case "submitAnswer":
        result = submitAnswer(room.state, { playerId, entityId: msg.payload.entityId }, now, deps);
        break;
      default:
        return;
    }
    if (result.error) ws.send(JSON.stringify({ type: "error", payload: { error: result.error } }));
    apply(room, result);
  });

  ws.on("close", () => {
    room.sockets.delete(playerId);
    apply(room, disconnect(room.state, playerId));
    // Rooms are ephemeral: drop it once the last player leaves.
    if (room.sockets.size === 0) rooms.delete(code);
  });
});

// One timer drives every room's phase expiry. The engine decides what expiry
// means; this only supplies the clock.
setInterval(() => {
  const now = Date.now();
  for (const room of rooms.values()) {
    if (room.state.phaseEndsAt === null) continue;
    const before = room.state.phase;
    const result = expirePhase(room.state, now, deps);
    room.state = result.state;
    // Broadcast every tick so countdowns stay in sync, not just on transitions.
    broadcast(room);
    if (before !== room.state.phase) console.log(`${room.state.code}: ${before} -> ${room.state.phase}`);
  }
}, 1000);

server.listen(PORT, HOST, () => console.log(`footfinder on http://${HOST}:${PORT}`));
```

- [ ] **Step 4: Add the room-creation rate limit**

The spec requires this. Without it, anyone who gets the tunnel URL can create
unlimited rooms and grow the `rooms` Map without bound.

Add near the top of `src/server.js`:

```javascript
// Per-IP token bucket: 5 rooms, refilling one per minute. Rooms are cheap but
// unbounded creation is a memory leak with a URL anyone can share on.
const buckets = new Map();
function allowRoomCreation(ip) {
  const now = Date.now();
  const b = buckets.get(ip) ?? { tokens: 5, last: now };
  b.tokens = Math.min(5, b.tokens + (now - b.last) / 60_000);
  b.last = now;
  if (b.tokens < 1) { buckets.set(ip, b); return false; }
  b.tokens -= 1;
  buckets.set(ip, b);
  return true;
}
```

Then guard the handler:

```javascript
  if (req.method === "POST" && req.url === "/api/room") {
    if (!allowRoomCreation(req.socket.remoteAddress ?? "unknown")) {
      res.writeHead(429, { "content-type": "application/json" });
      return res.end(JSON.stringify({ error: "slow_down" }));
    }
    const code = newCode();
```

Note: behind a tunnel every request may share one source address, so this
throttles the whole tunnel rather than individual friends. That is the correct
trade for a private game — it caps total damage without needing real identity.

- [ ] **Step 3: Create public/app.js**

```javascript
const $ = (id) => document.getElementById(id);
const screens = ["home", "lobby", "picking", "answering", "reveal", "final"];

let ws, me = null, snap = null, clubs = [];
// Survives a reload so refreshing rejoins as the same player.
const saved = (k, v) => (v === undefined ? sessionStorage.getItem(k) : sessionStorage.setItem(k, v));

function show(name) {
  for (const s of screens) $(`screen-${s}`).hidden = s !== name;
}

async function connect(code) {
  clubs = await (await fetch("/api/clubs")).json();
  const pid = saved("playerId") ?? "";
  ws = new WebSocket(`${location.protocol === "https:" ? "wss" : "ws"}://${location.host}/ws?code=${code}&playerId=${pid}`);

  ws.onmessage = (e) => {
    const { type, payload } = JSON.parse(e.data);
    if (type === "identity") { me = payload.playerId; saved("playerId", me); send("join", { nickname: $("nickname").value.trim() }); }
    if (type === "snapshot") { snap = payload; render(); }
    if (type === "error") $("answer-status").textContent = payload.error.replace(/_/g, " ");
  };
  ws.onclose = () => { $("phase").textContent = "disconnected"; };
}

const send = (type, payload = {}) => ws?.send(JSON.stringify({ type, payload }));

function render() {
  if (!snap) return;
  $("phase").textContent = snap.phase.toLowerCase();
  $("room-code").textContent = snap.code;

  if (snap.phase === "LOBBY") {
    show("lobby");
    $("lobby-players").innerHTML = snap.players.map((p) => `<li>${p.nickname}</li>`).join("");
    $("start").hidden = snap.you !== snap.hostId || snap.players.length < 2;
  }
  if (snap.phase === "PICKING") { show("picking"); renderClubs(); }
  if (snap.phase === "ANSWERING") { show("answering"); renderRoundClubs(); }
  if (snap.phase === "REVEAL") { show("reveal"); renderResults(); }
  if (snap.phase === "FINAL") {
    show("final");
    $("standings").innerHTML = snap.standings.map((p) => `<li>${p.nickname} — <span class="pts">${p.score}</span></li>`).join("");
  }
}

function renderClubs() {
  const taken = snap.round.picks;
  const mine = taken[snap.you];
  $("club-grid").innerHTML = clubs.map((c) => {
    const takenByOther = Object.entries(taken).some(([pid, cid]) => cid === c.id && pid !== snap.you);
    return `<button class="club ${mine === c.id ? "mine" : ""}" data-id="${c.id}" ${takenByOther ? "disabled" : ""}>${c.name}</button>`;
  }).join("");
}

function renderRoundClubs() {
  const names = Object.values(snap.round.picks)
    .map((id) => clubs.find((c) => c.id === id)?.name ?? id);
  $("round-clubs").innerHTML = names.map((n) => `<li>${n}</li>`).join("");
  const answered = snap.round.answered[snap.you];
  $("answer").disabled = !!answered;
  $("answer-status").textContent = answered ? "Answer locked in." : "";
}

function renderResults() {
  const name = (id) => snap.players.find((p) => p.id === id)?.nickname ?? id;
  $("results").innerHTML = snap.round.results.map((r) =>
    `<li>${name(r.playerId)} — <span class="pts">${r.points}</span>${r.entityId ? "" : " (no answer)"}</li>`).join("");
  const best = snap.round.bestAnswer;
  $("best-answer").textContent = best
    ? `Best possible: ${best.name} (${best.points})`
    : "No player in the dataset covered any of these clubs.";
}

// Countdown ticks locally between snapshots so it looks smooth.
setInterval(() => {
  if (!snap?.phaseEndsAt) return ($("timer").textContent = "");
  const left = Math.max(0, Math.ceil((snap.phaseEndsAt - Date.now()) / 1000));
  $("timer").textContent = left;
}, 250);

$("create").onclick = async () => {
  if (!$("nickname").value.trim()) return alert("Pick a name first");
  const { code } = await (await fetch("/api/room", { method: "POST" })).json();
  connect(code);
};
$("join").onclick = () => {
  if (!$("nickname").value.trim()) return alert("Pick a name first");
  connect($("join-code").value.trim().toUpperCase());
};
$("start").onclick = () => send("start");
$("club-grid").onclick = (e) => {
  const btn = e.target.closest(".club");
  if (btn && !btn.disabled) send("pickClub", { clubId: btn.dataset.id });
};

let searchTimer;
$("answer").oninput = (e) => {
  clearTimeout(searchTimer);
  const q = e.target.value;
  if (q.length < 2) return ($("suggestions").innerHTML = "");
  searchTimer = setTimeout(async () => {
    const results = await (await fetch(`/api/search?q=${encodeURIComponent(q)}`)).json();
    $("suggestions").innerHTML = results.map((r) => `<li data-id="${r.id}">${r.label}</li>`).join("");
  }, 150);
};
$("suggestions").onclick = (e) => {
  const li = e.target.closest("li");
  if (!li) return;
  send("submitAnswer", { entityId: li.dataset.id });
  $("suggestions").innerHTML = "";
  $("answer").value = li.textContent;
};

show("home");
```
